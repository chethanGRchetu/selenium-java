@Test: Works as main method
-> Single class we can write multiple @Test annotation

@BeforeMethod: invoke before @Test method
@AfterMethod: invoke after @Test method
Both will execute for each test methods

@BeforeClass and @AfterClass: it will execute only once for each @BeforeMethod and @AfterMethod or for entire test class


heirarchy
@BeforeClass
    @BeforeMethod
        @Test
    @AfterMethod
    @BeforeMethod
        @Test
    @AfterMethod
@AfterClass

Assertions: Used to validate test method by passing certain assertion condition
